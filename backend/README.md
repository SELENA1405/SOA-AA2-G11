# Backend
Run through Compose from the project root as described in README.md. The container installs pyproject.toml and runs `uvicorn app.main:app --host 0.0.0.0 --port 8000` from /backend.

Dependency direction: presentation -> application -> domain; application -> infrastructure. Domain and infrastructure import no other project layer. Application adapters implement domain ports; the composition root wires the service. External database access goes through DataPort. Domain scenario.py owns business validation and calculations. HTTP routes contain no business logic.

The seven S18 routes are implemented: equipment catalogue (list and detail) and load plans (create or return, get, add, update and remove items). Request validation and the server-side total live in `domain/scenario.py`, ownership checks and persistence go through `application/service.py` and `infrastructure/postgres.py`, and errors are returned as `{"error_code", "message"}`. A missing or empty `X-Session-Code` header is 400. The session code is not authentication. A rejected request leaves the saved items unchanged. Unit tests: `python -m pytest` inside this folder.
